# 📊 DataPulse AI — AI-Анализатор Таблиц и Датасетов (Case 03)

DataPulse AI — мощный аналитический комбайн в эстетике **Linear-style Dark**, транслирующий вопросы на естественном языке в Pandas-код, визуализирующий матрицы корреляций и генерирующий PDF-отчеты в Telegram.

---

## ⚡️ Ключевой функционал

### 1. Linear-Style Dark Dashboard
- **3-колоночный интерфейс:**
  - *Слева:* Drag-and-drop зона для CSV/XLSX файлов и переключатель 4 предзагруженных датасетов (Титаник, Недвижимость, Spotify, Продажи).
  - *По центру:* Интерактивная тепловая карта корреляций (-1.0...+1.0), графики распределений и превью таблиц.
  - *Справа:* AI-ассистент с карточками статистических инсайтов (медиана, дисперсия, межквартильный размах, детекция выбросов по методу Тьюки/IQR).
- **Безопасное исполнение кода:** Встроенный AST-валидатор (Abstract Syntax Tree), блокирующий любые небезопасные вызовы (`eval`, `exec`, `os`, `sys`, `subprocess`, `open`).

### 2. Telegram-бот DataPulse (Aiogram 3.x)
- Прием табличных файлов (`.csv`, `.xlsx`) в чат.
- Автоматический статистический аудит данных (пропуски, типы, аномалии, ключевые корреляции).
- Компиляция и отправка многостраничного PDF-досье (fpdf2) прямо в диалог.

## 🚀 Запуск и тестирование

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-дашборда
```bash
python web/app.py
# Дашборд доступен: http://localhost:8003
```

### 3. Запуск Telegram-бота
```bash
python bot/bot.py
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
